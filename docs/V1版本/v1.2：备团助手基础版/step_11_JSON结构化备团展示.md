# Step 11：JSON 结构化备团展示

## 这一步做了什么

- 让 AI 全文备团直接返回 JSON，而不是返回 Markdown 后再靠规则拆分。
- 后端把 JSON 解析成稳定字段：总览、必须知道、时间线、备团工作流、NPC、线索、地点、风险、检查清单。
- 前端不再把 AI 结果当作长文本展示，而是按结构渲染：
  - 时间线：节点式思维导图。
  - 备团结构地图：工作流卡片。
  - NPC 和重要线索：卡片。
  - 地点、风险、检查清单：独立区域。

## 可以怎么用

1. 进入“备团助手”标签页。
2. 点击“打开备团会话”。
3. AI 会读取 PDF 转换后的全文资料，生成结构化 JSON。
4. 页面会把 JSON 自动展示成时间线、工作流和卡片。

## 修改能力

- 每个结构区块下面都有一个“AI 重整”输入框，可以单独告诉 AI 这一部分怎么改。
- 底部保留“JSON 草稿编辑”，需要精确手动修改时可以直接编辑 JSON。
- 保存后，前端会重新读取结构化数据并更新展示。

## 现在的边界

- AI 需要稳定输出合法 JSON；如果模型返回格式严重错误，后端会明确报错。
- 当前仍保留旧的规则式结构提醒作为兜底，但主展示已经切换到 AI JSON 结果。
- 结构化数据目前覆盖备团常用字段，后续可以继续扩展为更细的场景、怪物、手牌、结局分支。
