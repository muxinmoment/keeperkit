# 分阶段路线图

## 总体思路

KeeperKit 的路线不适合一口气做成“完整平台”，更适合按阶段长出来。

从产品角度看，可以分成四层：

- MVP
- V1
- V2
- 长期愿景

## MVP

MVP 的目标是把最基础的闭环跑通。

建议包含：

- 规则书 RAG
- 模组导入
- 模组问答
- 基础来源展示

这一步重点是“能用”。

## V1

V1 的目标是让 KeeperKit 真正开始像一个模组助手。

建议包含：

- 模组结构视图
- 时间线整理
- NPC / 线索 / 地点抽取
- 备团笔记
- 改写建议预览

这一步重点是“能帮守秘人干活”。

## V2

V2 更适合把产品带到跑团过程中和跑团之后。

建议包含：

- 跑团现场模式
- 玩家角色卡
- 跑团记录
- 现场辅助
- 复盘系统

这一步重点是“能陪着团走一段”。

## 长期愿景

长期愿景可以继续往下长成：

- 完整跑团闭环
- 图片生成与资产管理
- 模组创作
- 插件化
- 多规则系统
- 云同步和多设备

这部分是 KeeperKit 的终局想象，但不应该反过来压住当前节奏。

## 阶段判断标准

每一阶段都应该问自己几个问题：

- 是否已经真正解决了当前最痛的工作？
- 是否能明显降低守秘人的门槛？
- 是否保留了原文、建议和版本边界？
- 是否为下一阶段留了结构入口？

如果这些问题都能答上来，这一阶段就算站住了。
